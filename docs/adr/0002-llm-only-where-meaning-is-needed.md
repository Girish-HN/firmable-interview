# LLMs are used only where meaning is needed; Signals and the Priority Score are computed

The brief is "AI-native", so a reader may expect an LLM to judge each company's risk. We deliberately don't: anything that can be computed (CVE/KEV/EPSS lookups, exposed ports, certificate expiry, the Priority Score itself) is a deterministic rule, because it must be reproducible, cheap at billions of Banners a month, auditable by a seller, and immune to the vendor silently swapping models. The LLM gets exactly two jobs that need understanding of meaning: classifying a Company's industry from its page title/HTML, and attributing ambiguous Banners that rules can't resolve. Both are measured on the Golden Set (precision, recall, cost per 1k Companies) and re-run on every prompt or model change.
